# Life OS v0.6 使用说明

Life OS 是给个人使用的记录与行动工具，不是打卡考核。可以只用其中一部分；不使用某个模块、休息或中断连续记录都不会扣减已获得的经验。

## 从今天开始

1. 首页最上方是生活看板。点睡眠卡片记入睡 / 醒来，点「记一段活动」填写工作、学习、运动和休息的起止时间；点「补记 / 修改」写饮食、日常和自评分。图表只统计实际记录的时段，不从文字推算。
2. 生活看板下方的「今日任务」包含自己安排的固定习惯和一次性事项。做完一项就点旁边的圆圈；没有待办时，可以去「计划」添加，也可以留空。
3. 状态记录是可选的。保存后，Life RPG 按现有规则生成三条行动建议；它们和「今日任务」分开展示，不会互相自动复制，也可以忽略。
4. 完成事项后按现有规则领取 XP、资本经验和技能经验；每个行动只会完成一次。休息或漏记不会扣经验。
5. 「每日记录」可以给今天打 1–10 分，并选填醒来时间、饮食、做过的事、不顺心的事和运动情况。它们是自我观察，不是考核；没有运动、漏记或给低分都没有惩罚。
6. 「今日小结」是可选的。保存只记录趋势数据，不会发放或扣减经验。
7. 想写多条原始记录、查看时间线和修订历史，使用「自我历史学」。

## 计划的三种类型

睡眠跨午夜需选择不同日期，可分开记录夜间睡眠和午睡。首页按醒来日显示睡眠，时间分布按当天部分计算；未记录不算作零分或休息。具体操作、计算口径及实机截图见 [生活看板说明](today-life-dashboard.md)。

- **一次性事项**：只需要完成一次的任务。
- **固定习惯**：每天最多领取一次奖励，下一自然日可再次完成。
- **长期目标**：可拆成阶段；勾选阶段时沿用现有的 30 XP 规则。

未完成的事项可以保留或编辑。删除需要明确确认；删除列表项不会扣回已经获得的经验，也不能在应用内撤销。随机灵感卡片仅供参考，不会自动变成计划或发放奖励。

## 两种文字记录

Life RPG 的「每日记录」按日期保存一条记录，包括自评分、醒来时间、饮食、活动、运动情况和简短回顾；字段都可选。再次保存同一天会更新该日期的记录，当前版本不保留修订历史。每日自评分和状态滑块都不会改变经验规则。自我历史学可以保存多条原始记录，编辑时保留修订历史；分析结果保存在独立的数据字段，不自动覆盖原文。

## 数据安全、备份与离线

Life RPG 使用浏览器 localStorage；自我历史学使用 IndexedDB。使用「更多 → 设置与备份 → 导出 JSON 备份」下载 Life RPG 数据；在自我历史学的菜单中单独导出该模块的备份。清除浏览器网站数据、换浏览器或换设备之前，先分别导出备份。

浏览器只允许网页读取同源数据。同源要求协议、域名和端口一致；不同网站地址不能互相读取本地存档。跨地址迁移必须由用户先导出，再在目标地址显式导入。本版本不做自动迁移或两套记录自动合并。

首次访问时需要联网加载应用资源。成功加载后，已缓存页面可离线打开；清理浏览器数据后需要重新联网访问。存档本身不上传到 GitHub Pages。
