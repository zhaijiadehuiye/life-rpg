# Life OS v0.6 使用说明

Life OS 是给自己使用的生活记录与行动工具。可以只用其中一部分；休息、漏记或中断连续记录，都不会扣减已有经验。

## 第一次打开

桌面左侧最上方点「使用引导」，手机点顶部「使用引导」或「更多 → 使用引导」。点「开始操作引导」会带你走过今天、每日记录、计划和历史记录四个页面；每一步都在实际页面操作，随时可以退出。

没有成长档案时，可以先建立档案，也可以直接写随手记。不会自动把示例写进你的真实档案。

## 每天可以怎样用

1. **早上记作息**：在「今天」点睡眠卡片，填写入睡与醒来日期、时间。跨午夜注意选对日期；午睡可以另记一段。
2. **白天随时记**：「记一段活动」填写已发生的工作、学习、运动或休息时段。有事想留下来时，去「每日记录 → 随手记」写几句话。
3. **晚上简单总结**：「每日记录 → 每日总结」选填吃了什么、做过的事、运动、困难和感受，可以给当天打 1–10 分。点保存后，内容会显示在今天的面板上。
4. **想做事时再加计划**：生活看板下方的「今日任务」显示自己安排的小事。完成后点圆圈；没安排也可以留空。
5. **有空再回看**：「历史记录」里一起查看每日总结和随手记，可以搜索或选择日期。
6. **有件事没按预期**：在「今天 → 今天想复盘的事」点「记一次复盘」，给下次留一个小办法。

每项都能跳过，不必每天把所有表单填满。

## 每日总结和随手记怎么选

| 用法 | 每日总结 | 随手记 |
| --- | --- | --- |
| 适合记录 | 作息、饮食、运动、当天感受 | 一件经历、一段想法、想保留的原话 |
| 一天可以写几份 | 一份，可继续修改 | 多条 |
| 修改时 | 更新当天总结 | 追加新版本，保留首次原文和旧版本 |
| 在哪里回看 | 今天和历史记录 | 每日记录的最近记录、历史记录 |

按需要选一个即可，不用重复填写。随手记的「整理文字」需主动点击，它与原文分开保存，不会覆盖原文或修订；摘录仍需要自己核对。

## 怎样看睡眠和时间图

睡眠按醒来的日期归属，可合计夜间睡眠与午睡；首页起止显示最长一段。时长来自你填写的起止时间估算。时间分布只算落在当天的部分，跨午夜会自动拆分。

灰色包含尚未记录和还没到的时间，不代表休息或浪费。7 天均值排除未记录的日子；明确填写的 0 小时仍有效。图表不会从日记文字或任务预计时长推算。旧版自报睡眠和醒来时间仍保留。

## 计划的三种类型

- **一次性事项**：只做一次，例如预约体检。
- **固定习惯**：每天最多领取一次奖励，下一自然日可再次完成。
- **长期目标**：可以拆成阶段；勾选阶段沿用现有的 30 XP 规则。

计划是想做什么，记录是实际发生什么。写日记或记时段不会自动勾任务。未完成事项可保留或编辑；删除需要确认。随机灵感和状态建议都可忽略，不会扣经验。

## 复盘与探索可以晚一点再用

- **失败复盘**：记录原本的预期、实际情况、可能因素和下次只改的一件事。前两项必填，其他都能以后补。只记录你主动选择的事，不把未完成任务自动当失败。
- **回看线索**：看看最近常写什么、已有睡眠与完成情况如何一起出现，不自动判断因果。
- **想法与证据**：记一个待验证的解释，关联支持或反对它的随手记。调整相信程度会追加历史。
- **小实验**：试一个小改变，留下观察，按需要整理数值小结，不强制连续记录。
- **我的预测**：先记一个概率，以后核对是否发生；当时的概率保留。
- **定期复盘**：选一个月，留下自己的总结和下一步。再次复盘会保留旧版本。

失败复盘试过以后可以选「有帮助 / 没帮助 / 还没尝试」，再点「保存这次回看」。每次观察和修改都保留在「修改与回看历史」里；修改了调整办法后，旧观察仍归属旧版本，不会自动当成新办法的效果。

「查看全部日期」回看更早的事，日期筛选只显示当天的复盘。7 天统计只计算最新版本里自己选的标签，一件事的多个标签可以同时出现，次数不是失败率或原因判断。

除新增的失败复盘，其他功能来自原来的自我历史学，现在使用同一套导航与界面。旧档案直接可读，无需手动搬迁。[失败复盘图解](failure-review.md)。

## 备份、恢复和离线

打开「设置与备份 → 导出整站 JSON 备份」，把文件下载到自己设备。整站备份同时包含角色与生活记录、随手记与定期复盘档案、失败复盘及其历史。Markdown / CSV 方便阅读，不包含完整失败复盘，完整恢复请使用 JSON。

恢复时可在本页三个对应区域分别选择同一个整站文件：记录档案和失败复盘先预览再补充导入，重复项跳过，冲突内容保留独立副本；角色与生活记录会先显示预览，只有确认后才替换这一部分。旧备份没有失败复盘时跳过该区域，当前复盘不会因此清空。请先导出当前备份。

清理网站数据、换浏览器或换设备之前务必下载备份。同域的正式版与 PR 预览共用当前浏览器存档；不同域名无法直接读取彼此的数据，需要你显式导出 / 导入。

先联网完整打开一次，之后已缓存页面可以离线使用。版本更新后如果仍显示旧菜单，可再刷新一次；不要通过清除网站数据来更新。未保存的输入离开页面后不会保留。存档本身不上传到 GitHub Pages。
